kind: sensor
id: sdd-specs-on-stop
description: Link every id the specs cite and check them against plan.json, and refuse to stop while either fails.
signal: Stop
run: node "[[sdd-specs]]" link --if-changed && node "[[sdd-specs]]" check --if-changed || exit 2
---

When the agent stops with anything under the spec folder changed — what `git
status` reports there, staged or not — [sdd-specs](../../script/sdd-specs/index.md) links every citation and
then checks the whole set: ids, statuses, and `plan.json` against the stories
the specs hold. With nothing changed there, nothing runs.

Exit code 2 hands the fault back to the agent and keeps it working: fix the
citation, the status line or `plan.json`, rather than stop with a spec set that
disagrees with itself.
